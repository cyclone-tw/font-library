保留名稱是什麼

OFL 允許作者保留字型名稱。修改過的字型（包含只裁出部分字的網頁字型）不能再用這個名字，避免別人把改壞的版本當成原版。

  • 本庫有保留名稱的：{{RFN_LIST}}。
  • fontlib.py subset 會自動把裁切版改名，例如「字嗨」改成 FL bpmf-kai-std；CSS 的 font-family 用指令印出的名字。
  • 直接用 Google Fonts 載入不算你修改，不用改名。

署名怎麼放

每張卡都有「複製署名」。用了幾套就放幾行，位置選一個固定的地方：

  • 學習單、簡報：最後一頁或頁尾小字。
  • 網頁：頁尾，或「關於與聲明」頁的資料來源段。
  • 影片：片尾字幕或說明欄。

別人做的字型整理

2026-11-12 查到的現況：沒有找到專門整理「台灣繁體＋注音字型授權」的清單，所以這份自己維護。下面幾個可以參考：

  • jaywcjlove/free-font：最活躍的中文免費字型清單，每套有授權分類，但偏簡體，也不記版本和署名文字。
  • Google Fonts 的 METADATA.pb：每套字型一個資料夾，附授權原文與上游 commit。本 repo 的欄位設計參考它。
  • 中文網字計劃：把中文字型切片放上網頁 CDN，適合參考網頁載入做法。
  • ButTaiwan：注音字型規格 bpmfvs、芫荽、源樣系列的作者，是台灣注音字型最主要的一手來源。

在專案裡怎麼用

字型檔不放進 git；fonts.toml 記來源與授權，腳本負責下載、核對和裁字。

# 看有哪些字型、下載並核對 sha256
python3 scripts/fontlib.py list
python3 scripts/fontlib.py fetch bpmf-zihi-kai-std

# 裝到電腦給 Word、Pages 用；印出署名文字
python3 scripts/fontlib.py install bpmf-zihi-kai-std
python3 scripts/fontlib.py attribution iansui

# 網頁：只裁出頁面用到的字，通常只剩幾十 KB
uv run --with fonttools --with brotli python scripts/fontlib.py \
  subset iansui --text-file lesson.html -o fonts/iansui-lesson.woff2

樣張用的是各字型的裁切子集，只含這頁用到的字；有保留名稱的字型，裁切版已改名。頁面產生日期 {{BUILT}}。
