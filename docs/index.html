授權怎麼看

授權可商用可修改、裁字要做的事
OFL-1.1可以可以，但有「保留名稱」的字型改過要換名字不能單獨賣字型檔；再散布字型檔要附授權原文
CC-BY-4.0可以可以作品上標示字型名稱與作者（用卡片上的「複製署名」）
CC-BY-ND-3.0-TW可以不可以：不能裁字、不能轉網頁字型標示「中華民國教育部」；只整檔安裝使用
政府資料開放授權條款可以可以全字庫可在此條款與 OFL 間擇一，本清單選 OFL

別人做的字型整理

2026-11-12 查到的現況：沒有找到專門整理「台灣繁體＋注音字型授權」的清單，所以這份值得自己維護。下面幾個可以參考：

  • jaywcjlove/free-font：最活躍的中文免費字型清單，每套字型有授權分類，但偏簡體，也不記版本和署名文字。
  • Google Fonts 的 METADATA.pb：每套字型一個資料夾，附授權原文與上游 commit。本 repo 的欄位設計參考它。
  • 中文網字計劃：把中文字型切片放上網頁 CDN，適合參考網頁載入做法。
  • ButTaiwan：注音字型規格 bpmfvs、芫荽、源樣系列的作者，是台灣注音字型最主要的一手來源。

在專案裡怎麼用

字型檔不放進 git。fonts.toml 記來源與授權，腳本負責下載、核對和裁字：

python3 scripts/fontlib.py list                     # 看有哪些字型
python3 scripts/fontlib.py fetch bpmf-zihi-kai-std   # 下載，核對 sha256
python3 scripts/fontlib.py install bpmf-zihi-kai-std # 裝到電腦給 Word、Pages 用
python3 scripts/fontlib.py attribution iansui        # 印出署名文字

# 網頁：只裁出頁面用到的字，通常只剩幾十 KB
uv run --with fonttools --with brotli python scripts/fontlib.py \
  subset iansui --text-file lesson.html -o fonts/iansui-lesson.woff2
樣張用的是各字型的裁切子集，只含這頁用到的字。有保留名稱的字型，裁切版已改名。字型授權以各上游原文為準。
