我是誰

我是 Cyclone。我相信教材從一開始就該為不同的孩子設計：看得懂、聽得到、點得到、寫得下。我致力以全方位學習設計（UDL）的理念規劃每一份教材，再和 AI 一起做成網站、練習單與學習遊戲，讓老師拿了就能用，孩子用自己的方式學會。

這個網站

教學字型庫整理台灣教學網頁與學習單可以使用的開源字型，每一套附樣張、白話授權說明與可以直接貼上的署名文字。免費、免登入、沒有廣告。奧瑞恩是奧瑞恩小學堂的吉祥物。

AI 怎麼參與

網站程式、版面與字型清單，是我和 AI 程式助理一起完成的。每套字型的授權欄位都是讀過上游授權原文後才填寫，並記下查證日期。奧瑞恩的插圖由 AI 生成，經過人工挑選。如果發現錯誤，歡迎到 GitHub 告訴我。

字型與授權原文來自各字型作者的官方發布處：GitHub、Google Fonts、政府資料開放平臺（全字庫）、教育部（標準楷書）。每套字型的授權寫在卡片與授權總表上，原文存在 repo 的 licenses/ 資料夾。

本站的字型清單、管理腳本與網頁程式以 MIT 授權公開。

本站沒有帳號，不蒐集任何個人資料，也沒有追蹤程式。網頁由 GitHub Pages 提供；介面文字與部分樣張從 Google Fonts 載入，瀏覽器會連到 Google 的伺服器下載字型。

One set of materials, a way in for every child.

Who I am

I'm Cyclone. I believe learning materials should be designed for different children from the start: easy to read, easy to hear, easy to tap, easy to write. I'm committed to planning every piece around the principles of Universal Design for Learning (UDL), then building it with AI into websites, worksheets and learning games, so teachers can use it right away and every child can learn in their own way.

cyclonetw.dev

This site

The Teaching Font Library lists open-source fonts that Taiwanese teachers can use in web lessons and worksheets, each with a specimen, a plain-language license summary and a ready-to-paste attribution line. Free, no sign-in, no ads. Aurelion is the mascot of Aurelion's Little School.

How AI is involved

The site code, layout and font list were built together with an AI coding assistant. Every license field was filled in only after reading the upstream license text, and the check date is recorded. Aurelion's illustrations were AI-generated and hand-picked. If you find a mistake, please let me know on GitHub.

Sources and licenses

Fonts and license texts come from each font's official release: GitHub, Google Fonts, Taiwan's open government data platform (CNS11643 fonts) and the Ministry of Education (Standard Kai). The license texts are kept in the repo's licenses/ folder. The font list, scripts and site code are released under the MIT License.

Privacy

No accounts, no personal data collected, no trackers. The site is hosted on GitHub Pages; interface text and some specimens load from Google Fonts, so your browser connects to Google's servers to download them.
